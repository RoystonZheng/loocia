## 一、信息源双入口模板

**适用场景**：同一来源既可由定时调度触发，也可由直接 API 触发。

```text
前置条件：配置已启用，凭证通过安全注入，数据库为空或已知基线
步骤：调度入口触发一次；直接入口触发一次；分别检查请求、持久化、去重、错误和统计
预期：两条入口遵守同一 source_kind 规则，结果可区分且不会重复写入
```

## 二、工具池与团队精选模板

**适用场景**：验证工具全集、团队精选集和用途分类的边界。

```text
步骤：新增/发现工具；加入团队精选；修改用途分类；取消精选；再次查询工具池
预期：工具池实体持续存在，团队关系独立变化，分类字段映射稳定，列表和详情一致
```

## 三、API 到 UI 链路模板

**适用场景**：接口响应被前端列表、统计卡片和错误态共同消费。

```text
步骤：验证成功响应；空数组；业务错误；网络错误；未知枚举；刷新或重新进入页面
预期：HTTP 状态、响应 envelope、字段类型、空态/错误态和恢复动作均符合契约
```

## 四、配置生命周期模板

**适用场景**：调度配置或发现配置的新增、编辑、禁用、删除和恢复。

```text
步骤：创建；编辑关键字段；禁用；验证运行中冲突；删除或回滚；重新创建同一标识
预期：状态转换有明确边界，运行中操作不破坏现有任务，删除后无残留，恢复可重建
```

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the internal aihot service end-to-end through the simplest real endpoint (`GET /api/public/version`), proving Go(nuwa) API + PostgreSQL + React shell all wire together, with zero LLM or data-source dependency.

**Architecture:** A nuwa-scaffolded Go HTTP service exposes `/api/public/version` (static config, matching the vendored `openapi.yaml` `PublicVersion` schema) and a `/healthz` that checks a live PostgreSQL connection. A React app shell fetches `/api/public/version` and renders it. This is the vertical slice every later sub-plan builds on.

**Tech Stack:** Go (nuwa scaffold, `net/http`-compatible router), PostgreSQL (`pgx`), React + 司内组件库, contract source of truth = `docs/references/openapi.yaml`.

```go
package health

import (
	"context"
	"net/http"
)

// Pinger is anything that can check backing-store liveness.
type Pinger interface {
	Ping(ctx context.Context) error
}

func NewHandler(p Pinger) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if err := p.Ping(r.Context()); err != nil {
			w.WriteHeader(http.StatusServiceUnavailable)
			_, _ = w.Write([]byte(`{"status":"down"}`))
			return
		}
		w.Header().Set("Content-Type", "application/json")
		_, _ = w.Write([]byte(`{"status":"ok"}`))
	})
}
```

```ts
// web/src/api/version.ts
export interface PublicVersion {
  apiVersion: string
  skillVersion: string
  updatedAt: string
  changelogUrl: string
  recentChanges: string[]
}

export async function fetchVersion(): Promise<PublicVersion> {
  const res = await fetch('/api/public/version')
  if (!res.ok) throw new Error(`version fetch failed: ${res.status}`)
  return (await res.json()) as PublicVersion
}
```

# 产品概览

## 项目目标

AI Cool 是团队内部的 AI 信息与工具沉淀平台。当前代码已经支撑 AI 资讯聚合、日报、精选内容、热点和知识图谱浏览；本次需求把平台扩展到“工具发现、测评记录、团队工具列表”的闭环。

## 目标用户

- 团队成员：查看 AI 动态、日报、热点和已沉淀的团队工具。
- 工具测评人：从 GitHub 候选工具中选择要测评的仓库，维护 Cooper 测评文档链接，并给出纳入或不纳入结论。
- 运营/维护人：维护工具发现配置、手动触发发现任务、手动补充 GitHub 仓库。

## 当前核心能力

- AI 资讯流：支持全部动态和精选内容。
- 日报：展示最新日报以及历史日报。
- 热点和图谱：展示热点主题、词云和词条相关内容。
- 详情页：服务端渲染 `/items/{id}`，在配置 LLM 时支持重新翻译。

## 本次工具发现需求

以 Cooper 文档《AI Cool 升级方案》第 5 部分为准，本期新增工具模块：

- 发现配置：关键词或 GitHub Topic 两种方式，支持手动和每周触发。
- GitHub 发现：使用官方 Repository Search API，不解析 GitHub Trending 页面。
- 手动添加：用户粘贴 GitHub 仓库 URL，系统调用 GitHub Repository API 入库。
- 状态闭环：`discovered -> evaluating -> included/excluded`，不设置“观察”状态。
- 测评记录：用户自己创建 Cooper 文档，AI Cool 只保存链接、测评人、开始时间、结果和完成时间。
- 团队工具列表：只展示完成测评且 `included` 的工具。

## 非目标

- 不自动创建 Cooper 文档。
- 不读取或校验 Cooper 文档正文。
- 不做站内测评编辑器。
- 不做 SSO/RBAC；操作人和测评人首期由用户手填。
- 不做工具执行、插件运行或能力包分发。

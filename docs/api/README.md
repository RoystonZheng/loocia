# 接口契约

本目录维护后端接口契约以及前端对接口字段、错误码和状态的使用方式。

## 文件索引

| 文件 | 内容 | 什么时候读取 |
|---|---|---|
| [`openapi.yaml`](../references/openapi.yaml) | 当前项目 OpenAPI 参考契约 | 修改公共 API 或联调前 |
| `<模块>.md` | 模块后端接口契约 | 开发或修改接口时 |
| `<模块>-front.md` | 前端字段和状态映射 | 前端接入或联调时 |
| `<系统>-external.md` | 对外或第三方接口契约 | 对接外部系统时 |

## 权威来源

- 后端事实源：接口定义文件、代码实现和 handler 测试。
- 人类可读契约：本目录下的接口契约文档。
- 前端消费契约需要记录字段如何落到界面、错误如何展示、mock 如何组织。

## 当前接口风格

当前公共读取接口以 `GET + query` 为主，位于 `server/internal/publicapi`，例如 `/api/public/items`、`/api/public/daily`、`/api/public/hot-topics` 和 `/api/public/graph/*`。

当前已存在的写接口主要是详情页重新翻译：`POST /items/{id}/retranslate`，响应使用 `{"ok": true/false}` 风格。工具发现写接口规划沿用 `{"ok": true, "data": ...}` 或 `{"ok": false, "error": "...", "message": "..."}` 的明确结果格式。

## 维护规则

### 命名规则

内部接口使用 `<模块>.md`，前端消费契约使用 `<模块>-front.md`，外部接口使用 `<系统>-external.md`。

### 新增和更新规则

新增独立接口域时新增文件；已有接口字段、错误码、鉴权或响应结构变化时更新原文件，并核对相关前端契约。

## 文档模板

接口文档包含用途、路径、鉴权、请求参数、响应结构、错误码、示例和兼容性说明。前端契约还应包含字段展示、空态、错误态和 mock 约定。
